# Release Notes - v1.0.0

🎉 **PocketLedger 1.0.0 is officially released!**

### What's New:
- **Full-Stack REST Architecture**: Powered by FastAPI 0.100+ with SQLAlchemy and SQLite.
- **Next.js 14 Web Frontend**: App router with Tailwind CSS, Lucide icons, and light/dark theme toggle.
- **Granular Financial Analytics**: Category distribution, cash flow trends, and budget tracking.
- **CSV Data Portability**: Streaming export and bulk-import with row-level validation.
- **Docker Support**: Multi-stage docker builds and one-command `docker-compose up` setup.
- **Comprehensive Test Suite**: Automated backend tests using pytest and frontend utility tests.
